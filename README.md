# PhishLens

Herramienta de análisis de correos de phishing que combina comprobaciones deterministas
(SPF, DKIM, DMARC, reputación de indicadores) con un modelo de lenguaje que interpreta
la ingeniería social del mensaje y genera un informe explicado.

Proyecto de la asignatura Proyectos de Ciberseguridad — U-tad.
